# Traffic-Light-VLSI
Verilog-based timer and sensor traffic light controller simulated in Vivado

## Project Overview
This project implements a traffic light controller using Verilog HDL and simulates its behavior using Xilinx Vivado.

## Designs
- **Timer-Based Controller:** Controls traffic light states using a timer.
- **Sensor-Based Controller:** Changes traffic light states based on sensor inputs.

## Source Files
- `Traffic_Light_Time.v` — timer-based design.
- `Traffic_Light_Time_tb.v` — timer testbench.
- `Traffic_Light_Sensor.v` — sensor-based design.
- `Traffic_Light_Sensor_tb.v` — sensor testbench.

## Tools Used
- Verilog HDL
- Xilinx Vivado
